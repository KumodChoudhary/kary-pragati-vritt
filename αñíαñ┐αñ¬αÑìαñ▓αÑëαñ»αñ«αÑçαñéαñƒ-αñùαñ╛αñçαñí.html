Render + Neon डिप्लॉयमेंट गाइड

कुल समय ~25–30 मिनट · खर्च ₹0 · डेटा कभी नहीं मिटेगा
परिणाम: https://kary-pragati-vritt.onrender.com/form जैसा स्थायी लिंक
📦 सबसे पहले: चैट के फ़ाइल-क्षेत्र से kary-pragati-vritt-deploy.zip डाउनलोड करें और अपने कंप्यूटर पर खोलें (एक्सट्रैक्ट करें)। उसकी सारी फ़ाइलें हम अगले स्टेप में GitHub पर डालेंगे।
1

GitHub पर कोड डालें (~5 मिनट)

  1. खोलें github.com → लॉगिन → दाईं ओर + → New repository
  2. Repository name: kary-pragati-vritt · चुनें Public · बाकी डिफ़ॉल्ट · Create repository
  3. नए पेज पर नीचे लिखा मिलेगा "…uploading an existing file" → उस uploading an existing file लिंक पर क्लिक करें
  4. अब अपनी एक्सट्रैक्ट की हुई फ़ोल्डर की सारी चीज़ें खींचकर (drag & drop) डालें:
    app.py · survey_config.py · requirements.txt · render.yaml · Dockerfile · .gitignore · README.md · templates फ़ोल्डर · static फ़ोल्डर
    (पूरा फ़ोल्डर खींच सकते हैं — फ़ोल्डर संरचना अपने-आप बन जाएगी)
  5. नीचे Commit changes दबाएँ → हो गया, कुछ ही सेकंड में फ़ाइलें दिखने लगेंगी
✅ चेक: रेपो पेज पर render.yaml और templates/ फ़ोल्डर दिख रहा है? तो स्टेप 2 पर जाएँ।
2

Neon — फ्री PostgreSQL डेटाबेस (~5 मिनट)

यही वह चीज़ है जो आपका डेटा हमेशा के लिए सुरक्षित रखती है — होस्टिंग के रीस्टार्ट पर भी उत्तर नहीं मिटेंगे।

  1. खोलें neon.tech → Sign up (GitHub/Google से) → मुफ़्त योजना
  2. Create project → नाम: kary-pragati-vritt · Region: जो निकटतम दिखे (जैसे Mumbai/Singapore) → Create
  3. बने पेज पर Connection string मिलेगी — Copy दबाकर कहीं नोट कर लें
    postgresql://user:पास@ep-xxx.aws.neon.tech/neondb?sslmode=require
⚠️ यह URL गुप्त है — किसी को न भेजें। इसे अगले स्टेप में Render को देना है।
3

Render — डिप्लॉय (~10–15 मिनट)

  1. खोलें render.com → Sign up → GitHub से लॉगिन (और GitHub को अनुमति दें)
  2. New + → Blueprint चुनें → अपना रेपो kary-pragati-vritt चुनें
    👉 यहाँ आपका render.yaml अपने-आप पढ़ा जाएगा — कुछ भी टाइप नहीं करना!
  3. नीचे पर्यावरण-चर (Environment Variables) भरें:
    नामक्या भरें
    DATABASE_URLस्टेप 2 की Neon URL पेस्ट करें
    ADMIN_PASSWORDअपना नया मजबूत पासवर्ड (admin123 नहीं!)
    SECRET_KEYकुछ न करें — अपने-आप बनेगा ✓
  4. Apply / Deploy दबाएँ → 2–3 मिनट निर्माण चलेगा (लॉग देखते रहें — "Your service is live")
  5. डैशबोर्ड में Settings → Environment से पासवर्ड बाद में भी बदल सकते हैं
✅ आपको दो लिंक मिलेंगे:
• फॉर्म (शेयर लिंक): https://kary-pragati-vritt.onrender.com/form
• एडमिन: https://kary-pragati-vritt.onrender.com/admin
4

परीक्षण (~3 मिनट)

  1. फॉर्म लिंक खोलें → एक परीक्षण उत्तर भरें → धन्यवाद पेज आए
  2. /admin खोलें → अपना नया पासवर्ड → डैशबोर्ड में परीक्षण उत्तर दिखे (10 सेकंड)
  3. ⬇ Excel डाउनलोड दबाएँ → असली साइट पर फ़ाइल सीधे डाउनलोड होगी (प्रीव्यू वाली समस्या यहाँ नहीं!)
  4. परीक्षण उत्तर हटाने के लिए डैशबोर्ड में 🗑 साफ़ करें
5
