# 📋 कार्य-वृत्त — हिंदी फॉर्म सिस्टम

**कार्य-वृत्त** के लिए पूरा सिस्टम — एक ही फॉर्म में **प्रथम भाग** (संस्कार परिवार योजना एवं राष्ट्र रक्षा यज्ञ) + **द्वितीय भाग** (प्रतिभा विकास केन्द्र):
- 📝 **हिंदी फॉर्म** — 9 खंड (प्रथम भाग: क–ड, द्वितीय भाग: क–घ), निर्देश बैनर, अधिकतर संख्यात्मक उत्तर
- 🗓 **माह अपने आप** — टाइटल व अंतिम तिथि हर माह IST के अनुसार खुद बदलते हैं
- ➕ **योग स्वतः** — वर्तमान + लक्ष्य = योग, भरते ही अपने आप (सर्वर पर दोबारा सत्यापित)
- 🔗 **शेयर लिंक** — कोई ईमेल/खाता नहीं, कोई भी भर सकता है
- ⬇ **Excel** — single combined, हिंदी हेडर, हर डाउनलोड पर ताज़ा (2 शीट: उत्तर + सारांश)
- 📄 **PDF-1 / PDF-2** — दोनों भागों की अलग-अलग PDF, हर table में प्रांत column
- 📊 **डैशबोर्ड** — टेबल + इन्फोग्राफिक्स, हर **10 सेकंड में ऑटो-अपडेट**

## 🚀 चलाना

```bash
cd hindi-survey
pip install -r requirements.txt
python app.py
```
- फॉर्म: `http://localhost:8000/form` · एडमिन: `http://localhost:8000/admin` (पासवर्ड `admin123`)

## 🔗 शेयर लिंक
डैशबोर्ड खोलें → ऊपर "शेयर लिंक" कॉपी करें → WhatsApp/ईमेल/कहीं भी भेजें। उत्तरदाता को कुछ नहीं चाहिए।

## 📝 प्रश्न बदलना — `survey_config.py`

संरचना: `SECTIONS → items → fields`
- `grp` = खंड+क्रमांक (जैसे `"क.1"`) — Excel हेडर व तालिका में यही दिखता है
- फ़ील्ड प्रकार: `number` (संख्यात्मक), `text`, `textarea`, `radio` (विकल्पों के साथ)
- `required: True/False` · `placeholder` · `full: True` = पूरी पंक्ति
- `show_if` + `show_if_value`: सशर्त फ़ील्ड — दूसरे radio प्रश्न का उत्तर वह मान होने पर ही दिखेगा/ज़रूरी होगा (जैसे ग.3 में "नहीं" चुनने पर ही तिथि माँगी जाती है; Excel और तालिका में शर्त न पूरी होने पर "लागू नहीं" लिखा आता है)
- प्रश्न/खंड जोड़ना, हटाना, क्रम बदलना — बस यहीं बदलें

> **नोट:** आपके ड्राफ़्ट के खंड ख (1, 3) और घ (1, 2, 4) के क्रमांक 1, 2, 3… किए गए हैं।
> निर्देश का "मेरे व्हाट्सएप पर" हटाकर सामान्य किया गया है — चाहें तो `INSTRUCTION` में वापस जोड़ लें।

## ⬇ Excel में क्या मिलता है
- **शीट 1 "उत्तर"**: क्रमांक | समय | प्रांत | अध्यक्ष | क.1—जिले वर्तमान | क.1—सितंबर लक्ष्य | … (सभी हिंदी हेडर, आपके प्रश्नों के अनुसार) — फ़िल्टर + फ्रोज़न हेडर के साथ
- **शीट 2 "सारांश"**: कुल उत्तर, खंड-वार कुल योग (जैसे सभी प्रांतों के मिलाकर वर्तमान जिले बनाम लक्ष्य), प्रांत-वार मुख्य आँकड़े

## 📊 डैशबोर्ड के इन्फोग्राफिक्स
- स्टेट कार्ड: कुल उत्तर, आज, 7 दिन, अंतिम उत्तर
- 14-दिन का उत्तर ग्राफ़
- हर प्रश्न के लिए: **वर्तमान बनाम लक्ष्य** कुल-योग बार, **प्रांत-वार** तुलना बार, टेक्स्ट उत्तरों की सूची

## 🛠 अन्य
- **डेटा साफ़ करना:** डैशबोर्ड → "🗑 साफ़ करें" (या `data/responses.db` हटाएँ)
- **पासवर्ड बदलना:** परिवेश-चर `ADMIN_PASSWORD` (और `SECRET_KEY`) — नीचे डिप्लॉय निर्देश
- **लोकल में डेमो उत्तर:** अभी 3 नमूना उत्तर भरे हैं ताकि चार्ट/टेबल/Excel दिखें — असली उपयोग से पहले "साफ़ करें" दबाएँ

## 🌍 लाइव होस्टिंग (स्थायी शेयर लिंक) — योजना

> **डेटा कहाँ रहता है?** ऐप अब दो मोड में चलता है:
> - `DATABASE_URL` पर्यावरण-चर **न दें** → स्थानीय SQLite (`data/responses.db`) — सिर्फ़ अपने कंप्यूटर पर
> - `DATABASE_URL` दें (Neon/Supabase/Railway का PostgreSQL) → सारा डेटा **क्लाउड डेटाबेस** में — होस्टिंग पर भी कभी नहीं मिटता
>
> असली उपयोग (प्रांत अध्यक्षों से उत्तर) के लिए PostgreSQL वाला रास्ता ही चुनें।

### विकल्प 1 — रेंडर (फ्री) + Neon/Supabase (फ्री PostgreSQL) — अनुशंसित, ₹0
1. **Neon.tech** पर (या supabase.com) मुफ़्त खाता → नया परियोजना → PostgreSQL connection URL कॉपी करें (जैसे `postgresql://user:pass@ep-xxx.aws.neon.tech/neondb`)
2. इस फ़ोल्डर को **GitHub** पर पुश करें
3. **render.com** → New → **Blueprint** → अपना रेपो चुनें (यहाँ `render.yaml` अपने-आप पढ़ा जाएगा)
4. पर्यावरण-चर भरें: `DATABASE_URL` (ऊपर वाला URL) · `ADMIN_PASSWORD` (अपना पासवर्ड) · `SECRET_KEY` (अपने-आप बन जाएगा)
5. Deploy → लिंक मिलेगा: `https://kary-pragati-vritt.onrender.com/form` — **यही शेयर लिंक**
6. घूमती हुई सुई: फ्री प्लान पर ~15 मिनट सोने के बाद पहला खोलना ~50 सेकंड लेता है (फिर तेज़)

> ⚠️ Render के **फ्री** प्लान पर फ़ाइल-सिस्टम अस्थायी है — इसलिए SQLite यहाँ उपयुक्त नहीं; PostgreSQL URL देना ज़रूरी है (ऊपर स्टेप 1-4)।
> (चाहें तो पेड स्टार्टर ~₹600/माह पर Persistent Disk भी ले सकते हैं — लेकिन फ्री PostgreSQL बेहतर है।)

### विकल्प 2 — Railway (सबसे आसान; पहला प्रोजेक्ट फ्री क्रेडिट से, फिर ~₹5/माह)
1. **railway.app** पर खाता → New Project → **Deploy from GitHub** → रेपो चुनें (Dockerfile अपने-आप मिल जाएगा)
2. पर्यावरण-चर: `DATABASE_URL` (Railway अपने Postgres Plugin से, या Neon) · `ADMIN_PASSWORD` · `SECRET_KEY`
3. डेटा स्थायी रखने के लिए **Volume** जोड़ें (यदि SQLite उपयोग करें) — पर PostgreSQL क्लाउड में ही सुरक्षित
4. Deploy → `https://…up.railway.app` — यही शेयर लिंक

### विकल्प 3 — सिर्फ़ Render फ्री (बिना PostgreSQL) — ⚠️ नहीं चुनें
फ़ाइल-सिस्टम अस्थायी है; नए डिप्लॉय/रीस्टार्ट पर उत्तर मिट सकते हैं। केवल परीक्षण के लिए ठीक।

### 🔐 होस्टिंग पर अनिवार्य
- `ADMIN_PASSWORD` बदलें (डिफ़ॉल्ट `admin123` कभी न रखें)
- `SECRET_KEY` पर्यावरण-चर से दें (`generateValue: true` से अपने-आप बनती है)
- सब कुछ HTTPS पर चलेगा (होस्टिंग अपने-आप)

## 🔐 सुरक्षा
एडमिन पासवर्ड + SECRET_KEY बदलें; संवेदनशील डेटा होने पर HTTPS (होस्टिंग अपने-आप देती है) रखें; स्पैम से बचाव के लिए हनीपॉट फ़ील्ड है।
